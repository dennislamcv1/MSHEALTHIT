# MSHEALTHIT
## Microsoft Healthcare IT Support Specialist Professional Certificate
### Professional Certificate - 8 course series

Healthcare IT support is a fast-growing entry point into technology, and this program offers a job-ready path into the field. It is designed for career changers, graduates, and aspiring IT professionals who want to support patient care. Basic computer literacy is all you need. No coding, prior IT experience, healthcare background, or certifications are required.

You will build Tier 1 technician skills: resolving Microsoft 365 and Azure issues, handling protected health information securely, supporting clinical staff through Epic workflows, and documenting tickets for compliance.

You will gain hands-on experience with ServiceNow, Jira, Intune, Quick Assist, M365 admin center, Azure portal, Active Directory, Entra ID, Defender for Cloud, Copilot, Teams, Outlook, OneDrive, SharePoint, Purview, and Epic Hyperspace. You will also learn how Epic integrates with Microsoft systems, with concepts transferable to Cerner and Meditech.

By the end, you will triage tickets, follow troubleshooting procedures, perform warm transfers, and handle patient data securely. You will complete a career course and a 3-Ticket Shift Queue capstone simulation. This program prepares you for roles like Desktop Support Technician, Healthcare IT Support Specialist, EHR Support Specialist, and Service Desk Analyst.
